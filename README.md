# ChanlunAIApp 缠论多周期共振量化交易系统（全版本演进 V1.0 ~ V4.2）

本仓库完整收录 **ChanlunAIApp** 从初代三周期共振原型（`V1.0`）到机构级零先验实战定型版（`V4.2 Production`）的全部核心算法源码、回测引擎、独立第三方审计脚本、模块级消融实验以及可视化净值账本。

## 一、 底层缠论多周期几何引擎（`chanlun_engine.py`）

所有版本共享统一的底层缠论几何解析与三周期（日线 `Day` + 60分钟 `60m` + 15分钟 `15m`）区间套评分内核：

1. **标准 K 线包含关系处理（Merge）**
   - 按相邻非包含 K 线判定当前趋势方向（`up = high_i > high_{i-1}`）：
     - 向上趋势包含：取 `high = max(h1, h2)`，`low = max(l1, l2)`（高高原则）；
     - 向下趋势包含：取 `high = min(h1, h2)`，`low = min(l1, l2)`（低低原则）；
   - 同时累加合并 K 线对应的 `|MACD|` 红绿柱面积，保证后续笔背驰面积积分不因包含合并失真。

2. **顶底分型（Fractal）与笔（Stroke / Bi）**
   - 识别标准三 K 线顶分型（`top`）与底分型（`bottom`），同向分型取极值更新；
   - 异向分型间至少满足合并后 K 线索引跨度 `i - li >= 3` 且高低点严格突破，连接相邻顶底分型构成向上笔（`up`）与向下笔（`down`）；
   - 计算每一笔区间内的 `macdArea = sum(|MACD|)`，并与前一同向笔计算力度面积比 `divRatio = area_curr / area_prev`。

3. **中枢（ZhongShu / ZS）递推构造**
   - 由连续三笔重叠区间定义中枢上下沿：`ZG = min(b1.high, b2.high, b3.high)`，`ZD = max(b1.low, b2.low, b3.low)`；
   - 当满足 `ZG > ZD` 时中枢成立，统计中枢波动极值 `GG = max(high)`、`DD = min(low)`，后续笔若与 `[ZD, ZG]` 相交则自动延伸中枢。

4. **三周期区间套共振打分（`evaluate_asset`）**
   - **日线定方向（最高 +55 分）**：收盘站上日线 `ZG`（+30分）、位于 `[ZD, ZG]` 中枢震荡（+15分）、日线向下离开笔盘整底背驰一买 `divRatio < 0.75`（+25分）；
   - **60m 找结构（最高 +45 分）**：站上 60m 中枢 `ZG` 三买区（+25分）、60m 向上笔力度不背驰延续 `divRatio >= 0.70`（+20分）或向下笔底背驰 `divRatio < 0.80`（+15分）；
   - **15m 卡买点（-20 ~ +30 分）**：
     - 15m 向下笔回调不破 `ZG` 构成标准三买（+30分）；
     - 15m 向下笔 MACD 面积收敛背驰二买 `divRatio < 0.80`（+25分）；
     - 15m 向上笔 MACD 金叉延续（+10分）；
     - 15m 向上笔盘整顶背驰一卖 `divRatio < 0.75`（-20分）；
   - **盘口量价微观修正（-5 ~ +8 分）**：主买盘优势 `buyerDom >= +8%`（+8分），`buyerDom < -15%`（-5分）。

## 二、 全版本算法演进与改进详解（V1.0 → V4.2）

### 1. V1.0 初代原型：纯三周期打分 + 固定仓位轮动
- **对应代码**：`run_backtest.py`、`run_v1_20260615.py`、`backup_v1_original/`
- **核心算法**：
  - **两阶段选股漏斗**：
    - Stage 1 初筛：按成交额与主买优势桶（Bucket A 占 60%）+ 缩量浅幅回调承接桶（Bucket B `-4.8% <= pct <= +1.2%` 占 40%）筛选 Top-44；
    - Stage 2 精算：对初筛股执行日线/60m/15m 三周期缠论评分，满 45 分即触发买入；
  - **固定满仓配置**：单笔上限固定（如 10 万），无大盘择时，始终尝试满仓持有得分最高的标的；
  - **离场机制**：15m 向上笔盘整顶背驰一卖（`divRatio < 0.70`）或跌破 15m 中枢最低点 `DD`。
- **存在局限**：
  - 缺乏宏观牛熊状态识别，在 2018、2022 等单边熊市中满仓硬扛，15m 底背驰在日线主跌浪中频繁遭遇“背了又背”及中枢下移止损，长期回撤高达 70%+。

### 3. V2.0 / V2.2 牛熊四态环境识别与动态控仓版
- **对应代码**：`market_regime_v2.py`、`run_backtest_v2_regime.py`、`run_backtest_v2_1y_20_50_30.py`
- **核心算法与改进（相对 V1.x 的跨越）**：
  - **首创沪深300日线缠论+均线四态状态机（`classify_market_regime`）**：
    1. `🟢 BULL（强牛主升态）`：指数站上日线中枢 `ZG` 或 `Close > MA60 >= MA120`，总仓位上限 **100%**，每日限买 2 只，门槛 45 分；
    2. `🔵 RANGE（结构震荡/超跌一买态）`：中枢内部震荡或向下笔底背驰一买区，总仓位上限 **100%**，正常轮动；
    3. `🟡 WEAK（熊市弱势/高位急跌防守态）`：指数处于空头排列反弹段或顶背驰跌回 `ZG` 下方，**总仓位上限压降至 70%**，单笔金额缩至 **60%**，每日限买 1 只且门槛提至 **60 分**；
    4. `🔴 CRASH（诱多末端/高位闪崩停买态）`：熊市反弹末端无广度支撑（上涨家数占比 `<65%`）或牛市高位 20 日非背驰急跌，**禁止一切新开仓（0% 新开仓）**；
  - **新增熊市锁死初始止损（Ratchet Stop）**：在 `WEAK/CRASH` 态下，100% 锁死建仓时的初始止损位 `init_stop = 15m ZD * 0.99`，杜绝阴跌过程中 15m 新中枢不断下移导致的深套。

### 7. V3.3 终极版：过度乖离透支过滤 + 净值动态复利扩容 + 尾盘6分钟实盘流
- **对应代码**：`model_v3_3_ultimate.py`、`run_v3_3_duckdb_1_5_10y.py`、`duckdb_Backtest_engine.py`
- **核心算法与改进（相对 V3.2）**：
  1. **过度乖离透支过滤（Over-Extension / Impulse Filter）**：
     - **V3.3-A（日线透支过滤）**：当收盘价脱离日线中枢 `ZG` 超过 `+38%` 扣 25 分（超 `+28%` 扣 10 分），拒绝在日线第 3/4 笔衰竭末端接盘高位妖股；
     - **V3.3-B（60m 脉冲过滤）**：当收盘价脱离 60m 中枢 `ZG` 超过 `+25%` 扣 20 分（超 `+18%` 扣 10 分），十年期 DuckDB 实盘回测净值达 **+189.39%（Alpha +168.38%）**；
  2. **净值动态复利扩容（Dynamic Equity-Scaled Sizing）**：
     - 解决净值翻倍后固定 25 万单笔上限导致大量现金闲置的问题：
       $$\text{SingleCap}_t = \min\left(250\text{万}, \max\left(\text{BaseCap}, \text{Equity}_t \times \text{dyn\_pct}\right)\right)$$
     - 提供 `15%` 进取复利档（V3.3-A/B）与 `12%` 均衡复利档（V3.3-C）；
  3. **实盘级交易微观规则落地（DuckDB 唯一真源）**：
     - **尾盘黄金 6 分钟流水线**：`14:53:30` 读取信号 → `14:54:00` 卖出触发离场的持仓并当场释放可用资金 → `14:59:45` 校验 15m 底分型保护位并在收盘集合竞价 100% 买入；
     - **早盘 09:15~10:00 两步法跌停分流处置（`resolve_limit_down_two_step`）**：昨日尾盘封跌停无法卖出的持仓，次日若 `09:20` 后仍一字跌停则挂跌停价排队（情况A）；若竞价打开跌停低开，则转入 `09:30~10:00` 观察前两根 15m K 线，在第一波水下反抽高点卖出或破分时均线止损（情况B）；
     - **2023-08-28 分段真实税费**：2023-08-28 前印花税千 1，之后减半为万 5，叠加万 2.5 佣金与卖出滑点。

     - 止损线取 `eff_dd = max(当前15m_dd, frozen_15m_dd)`，绝不允许因阴跌产生更低新中枢而使止损线下移；初始止损保证至少 `4.5%` 呼吸空间（`min(zd * 0.99, price * 0.955)`）；
  3. **[模块3精粹] 果断五档波动率自适应牛熊阀门 + 动态 T1/T2 盾牌 + 二次函数连续乖离惩罚**：

     - **主板半年度调样**（V4.2-C/D 采用“55只高流动性领涨 + 45只大成交低波蓝筹”双通道；V4.2-A/B 采用纯流动性单通道，Top-75 直接入选 / Top-130 缓冲区保留）；

  5. **[模块5] 60m 主升浪首次 15m 顶背驰 50% 减半锁利 + 涨幅垫移动止盈**：
